How the Labs Work

Complete the labs in order. Each one builds on the previous lab's working copy and adds rows to the same results worksheet, so Lab 04 can compare everything you changed.

Important: the labs send real requests and consume AI credits from your allowance. Keep prompts to the ones provided, and use the session limit from Lab 03 for any extra experiments.
No live access? Each lab links to the supplied-data exercise in the Module 2 lab guide that covers the same decision on paper.

Lab Catalog

Lab 01: Measure Your Baseline

Set up the project and record what a vague prompt costs in VS Code and Copilot CLI.

Tool: VS Code + CLI · Time: ~25 min

Lab 02: Lean Context, Instructions, and Tools

Trim always-on instructions, move detail on demand, exclude noise, prune tools, and rerun with a scoped prompt.

Tool: VS Code · Time: ~35 min

Lab 03: Sessions and Spend Control

Narrow tools, cap spend, plan then hand off, compact a long thread, and run a capped prompt.

Tool: Copilot CLI · Time: ~30 min

Lab 04: Model Strategy and Evaluation

Compare two model arms by cost per accepted outcome, try a cheaper subagent, and write a habit plan.

Tool: VS Code + CLI · Time: ~35 min

Common Prerequisites

  • A GitHub account with a paid Copilot plan, and no policy blocking Copilot CLI or the models you plan to use.
  • Visual Studio Code 1.120 or later and Copilot CLI 1.0.48 or later, both signed in.
  • Git and Python 3.10 or later. The sample project uses only the standard library.
  • The workshop repository URL from your facilitator, <workshop-repo-url>. The sample project is in samples/credit-lab.

Security

Never paste credentials, tokens, customer data, or confidential source into prompts, instruction files, or memory. The sample project contains none.
