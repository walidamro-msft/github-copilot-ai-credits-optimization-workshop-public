Lab 01: Measure Your Baseline

Before you optimize anything, measure it. Run one task the way many developers do today and record what it cost in VS Code and in Copilot CLI.

VS Code + Copilot CLIL400~25 min

Scenario and Objectives

Your team's order-processing package has a failing test. You'll fix it with a short, vague prompt, the way it often happens under time pressure, and capture the cost so later labs have something to beat.

  • Set up a private, resettable copy of the lab project.
  • Run task T1 with a vague prompt in a VS Code agent session and record credits and context.
  • Run the same task in Copilot CLI and record /usage and /context.
  • Compare what fills the context window in each tool.

Build

Step 1: Check your client versions

  1. In VS Code, select Help > About and confirm the version is 1.120 or later.
  2. In a terminal, run copilot version and confirm 1.0.48 or later. Run copilot update if it is older.

Older clients still work but can show incorrect pricing and usage information, which would make your measurements unreliable.

Step 2: Create a resettable working copy

  1. Clone the workshop repository and copy the sample project out of it.
  2. Initialize a Git repository in the copy and commit the baseline.
  3. Copy the results worksheet next to the working copy, not inside it, so git stash never hides your notes.
  4. Run the tests.
PowerShell 
git clone <workshop-repo-url> workshop
Copy-Item -Recurse workshop/samples/credit-lab $HOME/credit-lab
Copy-Item workshop/samples/credit-lab/worksheets/results.md $HOME/credit-lab-results.md
Set-Location $HOME/credit-lab
git init
git add .
git commit -m "baseline"
python -m unittest
bash 
git clone <workshop-repo-url> workshop
cp -r workshop/samples/credit-lab ~/credit-lab
cp workshop/samples/credit-lab/worksheets/results.md ~/credit-lab-results.md
cd ~/credit-lab
git init && git add . && git commit -m "baseline"
python3 -m unittest

Expected result: Ran 8 tests and FAILED (failures=1) for test_bulk_discount_applied_before_tax.

Step 3: Run the vague prompt in VS Code

  1. Open ~/credit-lab in VS Code and open the Chat view.
  2. Start a new agent session. In the model picker, select Copilot Fusion with Fusion Standard. If your picker shows Auto instead, select Auto. Note the choice in the worksheet.
  3. Leave tools and reasoning at their defaults. Send exactly this prompt: 
    fix the tests
  4. Approve tool calls as prompted until the agent finishes.
  5. Hover over each response and add up the AI credits per turn.
  6. Hover over the context window control in the chat input. Record the total context tokens, the session's total credits, and the largest categories.
  7. In a terminal, run python -m unittest and record whether all tests pass, and how many follow-up prompts you needed.

Step 4: Reset the working copy

  1. Save the attempt and return to the baseline: 
    git stash push -u -m "lab01-vscode"
  2. Confirm git status shows a clean working tree.

Step 5: Run the same prompt in Copilot CLI

  1. In a terminal at ~/credit-lab, run copilot. Trust the folder when asked.
  2. Run /model and choose the same option you used in VS Code.
  3. Send fix the tests and approve tool calls until the agent finishes.
  4. Run /usage. Record the AI credits for each model row.
  5. Run /context. Record the total tokens and the values for Custom Instructions, System Tools, MCP Tools, and Messages.
  6. Exit with /exit, run the tests, then save the attempt with git stash push -u -m "lab01-cli".

Test and Verify

git stash list
  • git stash list shows lab01-vscode and lab01-cli.
  • git status shows a clean working tree at the baseline commit.
  • The worksheet has two Lab 01 rows with credits, context tokens, pass or fail, and rework turns.
  • You can name the largest recurring context category in each tool.
What to look for in your results

A vague prompt usually makes the agent search the repository, read several files, and sometimes edit the test instead of the code. Notice how much of the context is instructions and tool schemas before your prompt is even read. The sample's .github/copilot-instructions.md is deliberately bloated; you fix that in Lab 02.

Troubleshooting

SymptomCheck
python is not foundUse python3 or py, or install Python 3.10 or later.
No credits appear on hoverUpdate VS Code to 1.120 or later; older versions may not show usage.
/usage shows no AI credit valuesUpdate Copilot CLI; credit values appear for token-based-billing accounts.
Copilot Fusion isn't in the pickerUse Auto or the default model, and use the same choice in both tools.
The agent edited the test instead of the codeRecord it as a failed attempt. That outcome is part of the baseline.

Cleanup and References

Keep ~/credit-lab and the stashes for the next labs. No cloud resources were created; the only cost is the AI credits the two runs consumed.
