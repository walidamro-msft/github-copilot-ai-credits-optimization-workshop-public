AI Credit Session Limits

Put a soft ceiling on a single agentic task so it stops and asks before it runs away with your allowance.

Copilot CLIPublic preview~8 min

What Is a Session Limit?

An AI credit session limit caps the amount of GitHub AI Credits that Copilot can spend in a session. […] These session limits are soft limits. If a response is in progress when the limit is reached, that response completes before the session stops, so actual usage may slightly exceed the configured number.

Source: GitHub Docs, Setting an AI credit session limit in GitHub Copilot CLI

Session limits are available in Copilot CLI and the Copilot SDK. They are per-task controls; they don't replace the user-level budgets and spending limits that administrators use to govern monthly consumption.

Avoid surprises

Stop a task that keeps iterating before it consumes more than you expected.

Tune efficiency

Find the minimum credits that still produce a good result for a task type.

Important: the minimum session limit is 30 AI credits.
Note: GitHub's documentation currently describes the interactive limit two ways. The how-to page says it applies to the entire session and depletes as each message is processed. The CLI command reference describes /limits set max-ai-credits and --max-ai-credits as a soft maximum per response that resets with each user message. Check the /limits dialog in your CLI version, and observe the behavior in Lab 03.

Choosing a Limit

  • Start from measured data. Use /usage after a few representative tasks to see what a normal run of that task type costs.
  • Set the limit a little above a normal run so healthy tasks finish and runaway tasks stop.
  • When a task hits the limit, treat it as a signal: is the prompt missing a stop condition, is the context too broad, or does the task need a plan first?
  • For unattended runs, always pass --max-ai-credits, because a non-interactive run simply ends at the limit.

Key takeaway

Session limits are soft, per-task guardrails. They complement, not replace, the monthly budgets your administrators set.
