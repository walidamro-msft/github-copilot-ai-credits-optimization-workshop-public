Choosing the Right Interface

Use the smallest interface that can finish the task: unbilled completions for local edits, billed interfaces only when the work needs reasoning, coordination, or autonomy.

InterfacesDecision guide~10 min

The Smallest Sufficient Interface

Interface choice sets how much context is assembled, how many tools are advertised, and how many model calls a task triggers. Matching the interface to the task avoids two failure modes:

Too heavy

An agent session for a one-line rename spends turns exploring and planning work that completions would finish for free.

Too light

A chat question for a multi-file change stalls, then needs follow-ups and manual edits that cost more in total.

Tip: keep code completions and next edit suggestions on. They are unlimited on paid plans and do not consume AI credits, so in-flow typing never touches your allowance.

How to Choose

flowchart TD
    S([New task]) --> Q1{Local edit you can type?}
    Q1 -->|Yes| CMP[Completions and NES]
    Q1 -->|No| Q2{Only need an answer?}
    Q2 -->|Yes| ASK[Chat question]
    Q2 -->|No| Q3{Approach unclear?}
    Q3 -->|Yes| PLAN[Plan first]
    Q3 -->|No| Q4{Must finish unattended?}
    PLAN --> Q4
    Q4 -->|Yes| CLOUD[Cloud agent]
    Q4 -->|No| AG[Agent in IDE or CLI]
    class S external
    class Q1,Q2,Q3,Q4 neutral
    class CMP success
    class ASK,AG azure
    class PLAN accent
    class CLOUD warning

Green is unbilled. Blue and purple are billed interactive work. Orange is billed autonomous work you review afterward.

ScenarioSmallest sufficient interface
Rename a local variable and fix its three uses in one functionCompletions and next edit suggestions
Understand why a test fails, with the error in handOne chat question with the test file and error attached
Add a feature across four files and make the tests passPlan, then an agent session in VS Code or Copilot CLI
Bulk-update a config value across a monorepo from a scriptCopilot CLI in the narrowest directory that contains the change
Upgrade a dependency overnight and open a pull requestCopilot cloud agent with a clear stop condition

Key takeaway

Interface choice is about autonomy and tooling as much as price. Give the model exactly the autonomy the task needs, and keep free completions doing the small work.
