AI Credits Fundamentals

Read a Copilot bill the way the meter does: tokens by category, priced per model, converted to AI credits.

BillingPricing math~12 min

What Is an AI Credit?

GitHub AI Credits are the billing unit for metered Copilot usage in organizations and enterprises. […] Each token is priced based on the model used, and the total is converted into AI credits, where 1 AI credit = $0.01 USD.

Source: GitHub Docs, Usage-based billing for organizations and enterprises

The cost of an interaction depends on two things: the model and the number of tokens consumed. A quick question on a lightweight model can cost a fraction of a credit; a long agent session on a frontier model across many files costs more because it does more work.

Input

Your prompt plus everything attached: files, history, instructions, tool schemas, and tool results.

Cached input

Context reused from an earlier request in an active session, billed at a lower rate.

Cache write

Some models charge to store context in the cache the first time.

Output

What the model generates, including reasoning. Usually the highest price per token.

How Tokens Become Credits

flowchart LR
    P[Prompt and context] --> M[Selected model]
    M --> T1[Input tokens]
    M --> T2[(Cached input)]
    M --> T3[Cache write]
    M --> T4[Output tokens]
    T1 & T2 & T3 & T4 --> R[Per-model rates]
    R --> C[AI credits]
    class P external
    class M accent
    class T1 azure
    class T2 data
    class T3 warning
    class T4 danger
    class R neutral
    class C success

Each token category has its own per-model rate; the sum in USD is divided by $0.01 to give AI credits.

AI credits = (input × input rate + cached × cached rate + cache writes × write rate + output × output rate) ÷ $0.01

Worked example

One agent turn on GPT-5.3-Codex sends 40,000 input tokens, of which 35,000 are served from the cache, and produces 1,500 output tokens. GPT-5.3-Codex has no cache-write cost. Rates are per 1 million tokens.

CategoryTokensRate (per 1M)Cost
Fresh input5,000$1.75$0.00875
Cached input35,000$0.175$0.00613
Output1,500$14.00$0.02100
Total$0.0359 ≈ 3.6 credits

The same turn with a cold cache bills all 40,000 tokens as fresh input: $0.07 + $0.021 = $0.091, about 9.1 credits. Output was only 1,500 tokens yet cost more than all cached input combined.

Key takeaway

The two biggest levers are how much fresh context you send each turn and how much the model writes back. Cache reuse and concise output often matter more than the model's headline input price.

Completions and next edit suggestions keep working even when a user has a $0 budget or hits an enforced spending limit. Opening an interface is not the billing event; sending a request to a model is.

Included allowances

Copilot Business includes 1,900 AI credits per user per month and Copilot Enterprise includes 3,900. Allowances are pooled across the billing entity, reset at 00:00 UTC on the first day of each month, and do not carry over. A 100-seat Business organization shares one pool of 190,000 credits.
