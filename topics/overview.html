Why This Workshop Exists

When you use Copilot, the interaction consumes tokens: input tokens (what's sent to the model), output tokens (what the model generates), and cached tokens (context the model reuses or stores). Each token is priced based on the model used, and the total is converted into AI credits, where 1 AI credit = $0.01 USD.

Source: GitHub Docs, Models and pricing for GitHub Copilot

Under usage-based billing, two requests that look identical in the chat window can cost very different amounts. The difference comes from what you send (prompt, files, history, tool schemas), which model answers, how much reasoning it does, and how much it writes back.

This workshop gives you a practical playbook for the part you control as a developer or architect: interface choice, context, sessions, and models. Budgets and policies set by administrators bound total spend; your habits decide how much verified work each credit buys.

Measure tokens, not requests

Cost follows input, cached input, cache writes, and output, priced per model.

Optimize verified outcomes

Judge cost per accepted, working result, not cost per turn.

Trim the unnecessary

Cut repeated context and wasted turns without cutting the context the model needs.

Replace the Premium-Request Mental Model

If you used Copilot before usage-based billing, you probably counted premium requests and memorized model multipliers. Those habits no longer explain cost.

Old habitNew habit
Count premium requestsMeasure tokens and AI credits
Treat a request as one visible cost unitAccount for prompt, context, history, tools, and output
Memorize model multipliersRead per-model, per-token-category pricing
Minimize request countMinimize cost per completed, verified task
Important: shorter is not automatically cheaper. A prompt that omits needed context triggers follow-up turns that cost more in total than one well-scoped request.

What You Will Be Able to Do

  • Explain how tokens become AI credits and which Copilot features consume them.
  • Match each task to the smallest interface that can finish it.
  • Shrink recurring context: lean instructions, scoped customizations, pruned tools, clean search scope, and reviewed memory.
  • Decide when to continue, fork, compact, or start a new session, and hand off work without losing decisions.
  • Cap the spend of a single task with an AI credit session limit in Copilot CLI.
  • Choose models by full cost per accepted outcome and run a before/after evaluation on a fixed task set.
Note: this workshop does not cover administrator budgets, cost centers, or policies. Those controls bound total spend; this workshop covers what you control in each session.

Prerequisites

  • A GitHub account with a paid Copilot plan. Copilot Business or Copilot Enterprise is the target audience; the habits also apply to individual plans.
  • Visual Studio Code 1.120 or later and Copilot CLI 1.0.48 or later. Older versions can show incorrect pricing or usage information.
  • Git and Python 3.10 or later for the lab sample project.
Important: the labs send real requests and consume AI credits. Each lab keeps the work small, and Lab 03 shows you how to cap a session's spend.
