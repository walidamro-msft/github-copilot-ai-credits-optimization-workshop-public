GitHub Copilot AI Credit Optimization (Developer Workshop, L400)

GitHub Copilot now bills chat, agent, CLI, and cloud agent usage in AI credits, priced by tokens and model. This hands-on workshop shows developers and architects how to get more verified work from every credit without lowering quality.

What we will cover:
- How tokens become AI credits, and which Copilot features are billed
- Choosing the smallest sufficient interface for each task
- Lean context: instructions, customizations, tools, and Copilot Memory
- Sessions, prompt caching, compaction, and AI credit session limits
- Model strategy: Copilot Fusion and Auto, reasoning effort, subagents, cost per accepted outcome
- Four hands-on labs in VS Code and GitHub Copilot CLI

Who should attend:
- Developers, tech leads, and architects who use Copilot Chat, agent sessions, or Copilot CLI daily

Before the session:
- Paid Copilot plan (Business or Enterprise recommended), with Copilot CLI allowed by policy
- VS Code 1.120+ and Copilot CLI 1.0.48+, both signed in
- Git and Python 3.10+
- Note: labs use a small amount of your AI credit allowance

Duration: about 4 hours including breaks
